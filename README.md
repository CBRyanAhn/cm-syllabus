# 건설관리 강의계획서

Markdown을 소스로, HTML을 산출물로 두는 단일 페이지 강의계획서.
외부 파일·CDN·웹폰트 의존이 없어 오프라인에서도 열린다.

공개 주소: https://cbryanahn.github.io/cm-syllabus/2026-2/

## 구조

```
src/2026-2.md      ← 소스. 수정은 여기서만 한다
build.py           ← 빌드 스크립트
2026-2/index.html  ← 산출물. 직접 수정하지 않는다
index.html         ← 학기 목록 (빌드 시 자동 갱신)
```

## 갱신 방법

```bash
pip install markdown        # 최초 1회
python build.py 2026-2
```

1. `src/2026-2.md` 수정
2. `python build.py 2026-2`
3. 로컬에서 `2026-2/index.html` 열어 확인
4. 커밋·푸시 — 무엇이 바뀌었는지 구체적으로 적는다
   (예: `11/26 견적 6 주제 수정, 개인과제 2 제출일 11/24 → 11/26`)

새 학기는 `src/2027-1.md`를 추가하고 `python build.py 2027-1`.

## 페이지 동작

- 주차표는 700px 이하에서 카드형으로 전환된다 (가로 스크롤 없음)
- 오늘 날짜의 수업 행을 강조하고, 수업일이 아니면 다음 수업일을 강조한다
- 지난 수업 행은 흐리게 표시된다
- 인쇄(A4)·다크모드 대응
